# Holiday Calendar Demo

Private Vite + React demo that showcases date-fns `isHoliday` / `isWeekend` with public holiday data from [Nager.Date](https://date.nager.at/).

## Run

```bash
mise //pkgs/calendar-demo:dev
```

Or from this package:

```bash
pnpm install
pnpm dev
```

Open `http://localhost:5173`. Defaults: country `BG`, year `2026`.
